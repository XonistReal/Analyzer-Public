# Tracer anchors and local name alias - 0.13.1

**Tracer origin** selects **Crosshair / Bottom / Top**. Crosshair is the default for missing older settings. Bottom and Top sit at the horizontal center, two framebuffer pixels inside their respective screen edge. Each tracer-producing module keeps its own selection: Tracers, Storage ESP and the block/entity finder modules, including Skeleton ESP. Finder and storage origin controls appear when their tracers are enabled. Region Map has no tracer output.

Origins are unprojected through the actual rendered projection and model-view transforms. This includes Minecraft's view bob, hurt transform, changing field of view, camera rotation and first/third-person camera placement. Native line shader scaling is included. The endpoint continues to follow its real entity/block; only the origin stays at the selected screen position. Existing **Target anchor → Center / Feet / Head** chooses the entity endpoint independently and retains saved values. Colors, range, through-wall choices and filter settings remain independent.

**Client → Name Changer** is opt-in. Enable it and edit **Alias**, which defaults to `Player`. The alias accepts 1–32 ASCII letters, numbers or underscores and is stored through the ordinary config/profile system. The module substitutes your own account name in displayed text and measures the same displayed glyphs so labels, wrapping and alignment follow the alias. It handles names split across styled text components without changing the source components, and updates existing chat presentation when the alias or enabled state changes.

The alias covers ordinary rendered chat, player-list text, scoreboards, name labels and Analyzer text drawn through Minecraft's text renderer. Editable contents of native text fields, books, signs and multiline editors stay unchanged so commands, caret positions, the alias editor and other input remain usable. Text visible inside those fields can therefore still show the real name. Read-only book author/header labels remain masked. Image/logo pixels, skins and external overlays are outside text replacement; other mods using custom text renderers can bypass it. Visual text above the bounded 65,536-character processing limit displays `[Long text hidden]` while the module is enabled.

This is local presentation only: the account/session name, profile, UUID, server player identity, original messages and outgoing chat/commands remain real. It is useful for hiding the displayed name while streaming; it does not rename you on the server. Disabling restores ordinary rendering. Server Privacy remains a separate module with separate settings.

Current deterministic and native acceptance, including its limits, is recorded in [VALIDATION.md](VALIDATION.md).
