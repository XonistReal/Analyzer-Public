Anarchy & Donut SMP

Made for anarchy

Bases stay hidden, fights end fast and servers read what your client sends. These are the modules you'll reach for first, described the way the module catalogue describes them.

Render · World

Find bases

  • Advanced Stash FinderRecords storage clusters by chunk, with real counts and local history.
  • Chunk FinderFlags building and farm evidence in received chunks. Some hits are natural.
  • Region MapA coordinate grid of your position and the stashes you've logged.
  • Storage ESPBoxes around loaded containers, colored by storage group.
  • X-rayReal ore textures with faded terrain, outlines, or ores only.

HVH · Combat · Player

Win fights

  • Crystal AuraScores reachable crystals by explosion exposure, with self and friend damage guards.
  • Anchor AuraPlaces, charges and detonates anchors outside anchor-safe dimensions.
  • SurroundBuilds a shell around the blocks you stand in, using normal placement.
  • Auto TotemSwaps an inventory totem into your offhand.
  • Hover TotemHold a key over a totem in your inventory to move it to the offhand.

Movement · Player

Travel and survive

  • Elytra BoostAdds a bounded gliding push, or fires real hotbar rockets when flight slows.
  • Auto WalkHolds a movement key while the game is focused.
  • GlideLimits fall speed outside fluids. Legit mode opens your elytra.
  • Safe WalkStops you at ledges, or sneaks near an edge.
  • Auto EatStarts eating below your hunger threshold and keeps going until full.

Client

Stay private

Both modules work on your side of the connection.

  • Server PrivacyEight protections, on by default: a vanilla brand, no channel announcements, guarded translation and keybind probes, checked resource-pack downloads and more.
  • Name ChangerShows a local alias for your name in labels and chat. Your account and the messages you send stay unchanged.

Finders read the chunks your client has already received. Stash results are candidates to check, and Region Map is Analyzer's own grid, not Donut SMP's region numbers. Server Privacy cuts specific leaks; it does not hide your account, your IP or how you play.

Install

Playing in three steps

Pick how you launch the game. You'll use your own Minecraft account; releases never include accounts, worlds or settings.

  • Minecraft Java 1.21.4
  • Java 21
  • Fabric Loader 0.16.14
  • Fabric API 0.119.4+1.21.4
  1. Download Analyzer-0.15.0-Prism-1.21.4.zip from the latest release.
  2. Drag the ZIP onto Prism, or choose Add Instance → Import and select it.
  3. Pick your Minecraft account and Java 21, launch, and press Right Shift.

The ZIP already contains Fabric API, so there's nothing else to download.

  1. Create a Minecraft 1.21.4 instance with Fabric Loader 0.16.14 and Java 21.
  2. Put analyzer-0.15.0.jar and the matching Fabric API jar in its mods folder.
  3. Keep exactly one Analyzer jar, launch, and press Right Shift.

The -sources.jar is for reading code. Install the plain runtime jar.

git clone https://github.com/XonistReal/Analyzer-Public.git
cd Analyzer-Public
./gradlew build moduleCatalog

Needs a Java 21 JDK. In Windows PowerShell run .\gradlew.bat build moduleCatalog instead. The mod lands in build/libs/analyzer-0.15.0.jar.

Good to know

  • Gameplay automation starts disabled on a fresh install.
  • Settings, profiles and friends live in config/analyzer/.
  • Each release lists checksums in SHA256SUMS.txt.
  • Iris and Sodium compatibility hasn't been confirmed for every feature.
