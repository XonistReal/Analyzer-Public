# Native captures

These PNGs come from the actual Minecraft framebuffer. The 0.4.0 captures include all three menus, eleven 60% HUD variants, world effects and model/hand/item cosmetics. They are render output rather than mockups. The complete current runtime log and scope limits are in ../VALIDATION.md.

Files named analyzer-readable-* show corrected font sampling. Files named analyzer-60-* show smaller HUD panels with readable text at 1280x800 or 1920x1080. Cosmetic captures show selected implemented modes; not all available modes received screenshots. Earlier release images remain for historical reference.
