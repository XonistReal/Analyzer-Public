# Home screen reference board

The user supplied these five phone captures on October 12, 2026 and selected **Minecraft panorama** as the default background. They are unchanged comparison images for the design documentation; Temple's branding, scene and shaders are not runtime assets. Analyzer uses Minecraft's own panorama and original GLSL for the alternative Orbit background and translucent surfaces.

| Reference | Design used in Analyzer |
| --- | --- |
| [1 — Panorama](design/home-references/reference-1-panorama.jpg) | Open landscape, left navigation, small welcome/brand area, a large wordmark and quiet footer links. |
| [2 — Options](design/home-references/reference-2-options.jpg) | Two columns of settings over a softened background. Analyzer keeps actual Minecraft settings and callbacks. |
| [3 — Orbit](design/home-references/reference-3-orbit.jpg) | Optional starfield and gold disk around a dark lens. Analyzer's procedural art has its own layout and shader. |
| [4 — Singleplayer](design/home-references/reference-4-worlds.jpg) | Persistent navigation with a substantial translucent panel for the real world list and its actions. |
| [5 — Multiplayer](design/home-references/reference-5-servers.jpg) | The same shell around the actual server list, add/direct/refresh actions and native selection controls. |

The implementation and actual native captures are recorded in [Home controls](HOME-SCREEN.md). The module-menu direction remains separate in [UI references](UI-REFERENCES.md); Studio, Workspace, Classic and Compact remain available.
