|---|---|

These commits were reconstructed from saved release source ZIPs during this backup. They preserve the versions we actually saved; they do not invent earlier development commits or dates. Included file bytes were checked against the corresponding archives.

Raw `.log` files are omitted from Git snapshots because historical logs contain local machine paths. Sources, validation summaries, native screenshots, build files, module data, licenses and pinned third-party sources/artifacts remain. The private GitHub releases also retain the original archived downloads and their SHA-256 checksum files, including the original logs. Earlier validation describes the scenarios tested at that time; it does not establish the newer terrain protections.

Release 0.1.0 has a Fabric bundle; subsequent versions have native Prism bundles. The local updater paths in those bundles need reconfiguration on another PC. See [Moving PCs](MOVING-PCS.md) for importing, cloning, switching tags and continuing development.
